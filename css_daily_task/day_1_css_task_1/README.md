# College Admission Form

A simple **College Admission Form** created using HTML and CSS.
This project demonstrates the use of HTML form elements and CSS styling to create a clean college application form.

## Features

* Applicant full name input
* Date of birth selection
* Email input
* Phone number input
* Permanent address textarea
* Country selection
* Course selection using radio buttons
* Joining date selection
* HSLC certificate file upload
* Required-field validation
* Styled **Apply Now** button
* Poppins Google Font
* Background image

## Technologies Used

* **HTML5**
* **CSS3**
* **Google Fonts – Poppins**
