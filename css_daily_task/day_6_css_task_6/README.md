# FlowSync – Work Smarter

A modern, responsive landing page for **FlowSync**, a fictional productivity and workflow management platform. This project was created as part of the **CSS Daily Task – Day 6** challenge.

## 🚀 Live Preview

Open `index.html` in your browser to view the website locally.

## 📌 Features

* Modern dark-themed UI
* Responsive navigation bar
* Hero section with call-to-action buttons
* Interactive dashboard preview
* Project statistics cards
* Productivity chart
* Features section
* Call-to-action section
* Responsive design for mobile, tablet, and desktop
* Hover animations and transitions
* Google Fonts integration using Inter

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Google Fonts – Inter**
* CSS Grid
* CSS Flexbox
* CSS Gradients
* CSS Media Queries
* CSS Transitions & Animations

## 🎨 Design Highlights

The website uses a dark navy color palette combined with purple gradients to create a modern SaaS-style interface.

### Main Sections

1. **Navigation**

   * FlowSync logo
   * Features, Solutions, and Pricing links
   * Get Started button

2. **Hero Section**

   * Main headline
   * Product description
   * Call-to-action buttons
   * Trusted company names
   * Dashboard preview

3. **Features**

   * Lightning Fast
   * Team Collaboration
   * Smart Analytics

4. **CTA Section**

   * Free trial call-to-action

5. **Footer**

   * Copyright information
   * Social media links

## 📱 Responsive Design

The layout adapts to different screen sizes using CSS media queries.

* **Desktop:** Two-column hero layout and three-column feature cards
* **Tablet:** Single-column hero layout
* **Mobile:** Stacked buttons, statistics, and footer content
