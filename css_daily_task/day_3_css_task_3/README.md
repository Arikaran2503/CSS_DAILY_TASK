# NAB Bank Website Clone

A responsive front-end website inspired by the **National Australia Bank (NAB)** website. This project was created using HTML and CSS to practice website layout, navigation bars, cards, buttons, images, dropdown menus, and footer sections.

## 🚀 Features

* NAB-style navigation bar
* Personal, Business, Corporate, About Us, and Help & Support navigation
* Login button
* Credit card promotional section
* Popular banking solutions
* Dropdown menus for banking products
* Home loan refinancing section
* Savings accounts section
* Business banking section
* Travel banking section
* Responsive-style card layouts
* Footer with:

  * Quick links
  * Policies and terms
  * Social media links
  * Disclaimer information

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts – Poppins
* Local images
